# Глоссарий

[English version](../../docs/02-project/glossary.md)

- **CLI** — интерфейс командной строки.
- **PID 1** — главный процесс контейнера, отвечающий за сигналы и сбор завершившихся дочерних процессов.
- **Pull-модель** — мониторинг периодически запрашивает метрики у цели.
- **Prometheus** — система мониторинга и временных рядов.
- **Metrics endpoint** — HTTP endpoint с метриками в формате Prometheus.
- **Sidecar** — вспомогательный контейнер рядом с основным.
- **Pushgateway** — компонент Prometheus для отдельных push-сценариев batch-задач.
- **Runtime layer** — переиспользуемый слой исполнения, независимый от бизнес-кода.
- **Оператор** — человек, команда, автоматизация или оркестратор, который конфигурирует и запускает MetricShell. Это не
  обязательно Kubernetes Operator.
