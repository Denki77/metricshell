# MetricShell: трассировка до ADR-001...ADR-015

[English version](../../../docs/07-delivery/01-traceability/requirements-research-adr-traceability.md)

**Статус:** Draft for implementation planning  
**Дата:** 2026-08-04

## Назначение

Этот документ описывает нормативную цепочку требований, исследований и решений, связывающую все архитектурные решения
MetricShell, начиная с PID 1 и управления workload. Его назначение — показать, каким архитектурным решением закрывается
каждое функциональное требование.

Нормативная цепочка:

```text
требование -> INV-001...INV-015 -> ADR-001...ADR-015 -> specification
```

Документ не заменяет спецификации, research reports и ADR. Он определяет порядок производства системы, зависимости между
решениями и первый эшелон задач.

Граница документа: `FR → ADR → Specification`. Исследовательские evidence доступны через ссылки ADR на соответствующие
INV.

## Статусы

- **Закрыто** — принятые ADR определяют архитектурную политику, а указанная specification закрывает публичный контракт,
  если он нужен.
- **Частично закрыто** — ADR задают границы, но требуемая публичная specification ещё не принята.
