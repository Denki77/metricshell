# ADR-018: Локальный transport Managed Aggregation и protocol legacy-клиентов

- **Статус:** Принято
- **Дата:** 2026-09-25
- **Владельцы решения:** maintainers MetricShell
- **Связанное исследование:** `INV-018 — Legacy Client and Transport Viability`
- **Доказательства:** [Отчёт INV-018](../../../research/INV-018/report.md)
- **Семантическая зависимость:** [ADR-016](ADR-016.md)
- **Зависимость concurrency:** [ADR-017](../../06-architecture/adr/ADR-017.md)

## Контекст

Managed Aggregation позволяет legacy и simple workloads отправлять instrumentation operations, пока MetricShell владеет
Managed Registry. Первые клиенты включают PHP 5.4, shell и short-lived CLI processes. Взаимодействие локально для одного
запуска MetricShell/workload и не должно требовать от clients полного snapshot или registry.

INV-018 сравнил Unix domain stream socket и local HTTP, проверил реальный PHP 5.4.45, multiprocess publishers,
startup/reconnect/restart, malformed и bounded framing, explicit versions, permission denial и persistent transport
matrices. Matching-прогоны macOS-host/LinuxKit ARM64 и Ubuntu-host/LinuxKit x86_64 прошли 41/41 assertions с fingerprint
`a5a256f20b747d561c24f4d3b6132c3bb486c21d23ccba6f464277d86033fb7d`.

## Решение

### Initial local transport

Managed Aggregation использует Unix domain stream socket как initial local operation transport.

Выбор основан прежде всего на local same-workload boundary: filesystem ownership/group/mode дают прямую security
boundary, TCP listener и network configuration не нужны, PHP 5.4 поддерживает Unix streams, short-lived CLI helpers
остаются простыми, а модель соответствует одному binary/process MetricShell и одной supervised workload.

### Initial operation protocol

- Каждый request содержит explicit protocol version. Initial version — `1`.
- Unix version 1 использует одну bounded newline-delimited JSON operation на connection и один JSON response.
- Один request содержит одну instrumentation operation; complete snapshots через этот transport не публикуются.
- Supported version 1 принимается. Missing, invalid и unsupported versions детерминированно отклоняются.
- Malformed, partial и over-bound frames детерминированно отклоняются и не становятся valid operations.
- Framing должен быть bounded. ADR не выбирает production byte bound. Prototype bound 64 KiB — только research evidence;
  точные resource limits выбирает INV-019.

### Контракт legacy-клиента

Clients остаются stateless относительно Managed Registry. Они не хранят complete snapshot, local metric registry или
cross-process shared registry state. Независимые processes могут отправлять individual instrumentation operations.

Clients программно различают как минимум:

- accepted outcome;
- transport/connect failure;
- protocol/framing failure;
- semantic/server rejection.

Numeric exit codes prototype не входят в architecture contract.

### Response, retry и startup boundaries

Transport предоставляет одну explicit response boundary. Точный registry-смысл successful ACK — например queued,
committed или deduplicated — определяется ADR-017. Этот ADR не задаёт concurrency, linearization, operation identity или idempotency.

Convenience client может выполнять bounded retry только когда connection establishment определённо не состоялся и
request определённо не был отправлен. Если отправка могла произойти, но response отсутствует, outcome неизвестен и
client не должен слепо повторять operation без idempotency semantics из ADR-017.

Local endpoint должен быть ready до ожидаемой публикации supervised workload clients. Prototype retry counts, delays и
I/O timeouts не являются production defaults.

### Epoch и permissions

Reconnect не требует client-side registry reconstruction. Новый process MetricShell создаёт новую пустую Managed Registry
epoch согласно ADR-016; persistence и replay не добавляются.

Unix socket использует filesystem permissions как security property. Точные UID, GID, mode и deployment configuration
относятся к configuration/delivery specification. Prototype mode `0660` этим ADR не предписывается.

## Альтернативы

### Local HTTP/TCP

Local HTTP реализован и прошёл те же functional и persistent-generator matrices. Он технически viable и может быть
добавлен позже, если этого потребует product scope.

Он не выбран initial mandatory transport, поскольку требует TCP listener и добавляет address/network-policy surface без
существенного улучшения обязательного same-workload local use case. Unix даёт более простую local security и operational
boundary. HTTP не объявляется плохим или медленным; benchmark timings — secondary environment-sensitive observations.

### Complete snapshots на стороне client

Отклонено для legacy clients Managed Aggregation, поскольку возвращает registry, synchronization и serialization
responsibilities, которые extension должен убрать. Snapshot mode остаётся доступным и не меняется.

## Последствия

### Положительные

- Реальные PHP 5.4, shell и short-lived helpers публикуют operations и остаются stateless.
- Initial local path не требует TCP listener или network configuration.
- Filesystem permissions дают простую local security boundary.
- Version, framing и outcome errors явны и детерминированы.
- Response boundary может принять ordering/idempotency решения ADR-017 без переопределения transport viability.

### Компромиссы

- Unix sockets локальны и менее удобны для отладки, чем HTTP/curl.
- Одна operation на connection несёт connection-setup overhead.
- Точные frame, connection, queue, CPU и RSS limits остаются до INV-019.
- Production permissions и deployment configuration требуют specification.

## Последующие работы

- ADR-017 задаёт concurrency, ordering, idempotency и точную successful-ACK semantics.
- INV-019 задаёт точные frame/resource limits и performance thresholds.
- INV-020 задаёт lifecycle freeze, in-flight handling и final state.
- Final normative Managed Aggregation specification включает принятый набор ADR.

## Границы решения

ADR не меняет ADR-004 или ADR-016, не выбирает production numeric limits/timeouts, retry counts, latency/throughput SLA,
не требует HTTP support и не определяет lifecycle/freeze behavior.
