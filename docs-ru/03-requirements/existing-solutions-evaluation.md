# Оценка существующих решений

[English version](../../docs/03-requirements/existing-solutions-evaluation.md)

Существующие решения оцениваются по единым критериям:

- совместимость с pull-моделью;
- изменения приложения;
- дополнительная инфраструктура;
- переносимость;
- lifecycle и exit semantics;
- финальное состояние коротких задач;
- безопасность;
- эксплуатационная сложность;
- производительность;
- зрелость и стандартизация.

Ни один вариант не считается заранее выбранным. Архитектурные решения должны ссылаться на проверяемые evidence.
