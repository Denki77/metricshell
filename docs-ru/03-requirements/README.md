# Требования

[English version](../../docs/03-requirements/README.md)

Раздел содержит нормативные требования проекта.

## Терминология требований

- **MUST / ДОЛЖЕН** — обязательно.
- **SHOULD / СЛЕДУЕТ** — ожидается, если нет документированной причины поступить иначе.
- **MAY / МОЖЕТ** — необязательно.
