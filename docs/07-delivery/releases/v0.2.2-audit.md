### Independent trust limitation

The downloaded key is `1776d2d0dbcfa7a609843981edb52638e37b32733c6b04b4286a79d368e80b70`.
This audit confirms signature consistency with that key, **not** independent authentication of the maintainer's key.
No separately authenticated trust anchor was supplied. The owner must distribute/confirm the full key through an
independent authenticated channel; installation guidance fails closed until consumers supply that key themselves.
Neither this report nor the key's signed same-origin checksum establishes independent trust.

### Reproduce the asset verification

Use an empty directory to download every asset listed by the public release API, preserving the API response:

```sh
set -eu
out=$(mktemp -d)
curl --fail --location --show-error --connect-timeout 10 --max-time 60 \
  https://api.github.com/repos/Denki77/metricshell/releases/tags/v0.2.2 --output "$out/release.json"
python3 - "$out" <<'DOWNLOAD'
import json
from pathlib import Path
import subprocess
import sys
out = Path(sys.argv[1])
for asset in json.loads((out / 'release.json').read_text())['assets']:
    if Path(asset['name']).name != asset['name']:
        raise SystemExit('Unsafe asset name')
    subprocess.run(['curl', '--fail', '--location', '--show-error', '--connect-timeout', '10',
                    '--max-time', '120', asset['browser_download_url'], '--output', str(out / asset['name'])],
                   check=True, timeout=130)
DOWNLOAD
python3 implementation/scripts/verify-published-assets.py "$out" "$out/release.json"
# Review evidence before removing the retained download directory:
printf 'Evidence directory: %s\n' "$out"
```

Without `TRUSTED_RELEASE_PUBLIC_KEY_HEX`, the verifier explicitly reports independent trust as UNCONFIRMED.
Set it only after authenticating the full key through another channel. OpenSSL 3 verifies the raw Ed25519 signature;
no new Python dependency is required. To verify GitHub attestations with a separately installed GitHub CLI:

```sh
gh attestation verify "$out/metricshell-linux-amd64" --repo Denki77/metricshell
gh attestation verify "$out/metricshell-linux-arm64" --repo Denki77/metricshell
```
